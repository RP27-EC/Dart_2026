# RoboMaster Judge System Simulator

## 项目简介

RoboMaster裁判系统数据结构Python实现，提供完整的比赛流程模拟，特别专注于飞镖机器人的发射控制与状态监控。支持GUI界面和命令行操作，可模拟真实比赛中的裁判系统数据传输。

## 功能特性

### 🎯 核心功能
- **完整比赛流程模拟**：从准备阶段到比赛结算的全流程模拟
- **飞镖系统专项支持**：专门针对飞镖机器人的发射控制逻辑
- **多目标类型支持**：前哨站、基地固定目标、基地随机目标、基地随机移动目标
- **灵活事件配置**：支持1次或2次飞镖发射事件
- **实时状态监控**：游戏状态、飞镖状态、倒计时等实时显示

### 🖥️ 用户界面
- **图形化界面**：基于DearPyGui的现代化GUI界面
- **串口管理**：自动检测可用串口，支持热插拔刷新
- **实时可视化**：进度条、状态指示器、彩色状态文本
- **快捷键支持**：空格键和回车键快速操作

### 📡 通信协议
- **标准裁判系统协议**：完全兼容RoboMaster官方协议
- **多频率数据发送**：1Hz比赛状态、1Hz飞镖信息、3Hz客户端指令
- **CRC校验**：CRC8帧头校验 + CRC16整包校验
- **可配置参数**：发送间隔、波特率、目标类型等

## 基本操作

1. **连接设备**：
   - 点击"Refresh"刷新串口列表
   - 选择目标串口
   - 点击"Connect Port"建立连接

2. **配置参数**：
   - 选择飞镖事件次数（1次或2次）

3. **开始模拟**：
   - 点击"Start One Round"开始一轮完整比赛
   - 使用快捷键Space或Enter快速启动
   - 观察实时状态和进度条

## 详细功能说明

### 比赛流程

模拟器按以下顺序执行完整的比赛流程：

1. **准备阶段** (1秒) - 比赛准备，系统初始化
2. **裁判系统自检** (1秒) - 系统自检，设备状态确认
3. **五秒倒计时** (3秒) - 比赛开始前倒计时
4. **比赛进行** (35-60秒) - 正式比赛阶段
   - 第1秒：触发第一次飞镖事件
   - 第30秒：触发第二次飞镖事件（如果配置为2次事件）
5. **比赛结算** (2秒) - 比赛结束，结果统计

### 飞镖事件流程

每次飞镖事件包含以下阶段：

1. **舱门开启** (5秒) - 飞镖发射口开始打开 （录制回来的bag发现大概是5.5s）
3. **发射倒计时** (20秒) - 20秒倒计时，飞镖发射口打开
4. **舱门关闭** (2秒) - 倒计时结束，舱门开始关闭

### 数据发送

模拟器按照RoboMaster官方协议发送以下数据：

- **比赛状态** (CMD_ID: 0x0001, 1Hz)：游戏类型、进度、剩余时间
- **飞镖信息** (CMD_ID: 0x0105, 1Hz)：飞镖倒计时、击打信息
- **客户端指令** (CMD_ID: 0x020A, 3Hz)：发射口状态、指令时间
- **比赛结果** (CMD_ID: 0x0002, 一次性)：比赛结束时的胜负结果

## 配置选项

### 串口配置
- **端口选择**：自动检测或手动选择串口
- **波特率**：固定115200（符合官方标准）
- **发送间隔**：默认100ms

### 飞镖配置
- **目标类型**：(这个目前没有用)
  - Outpost (前哨站)
  - Base Fixed Target (基地固定目标)
  - Base Random Target (基地随机目标)
  - Base Random Moving Target (基地随机移动目标)
- **事件次数**：1次事件或2次事件
